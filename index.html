60-second workflow

From release page to local archive.

Confirm Python

Open PowerShell or a terminal and run python --version. Python 3.9 or later is recommended.

Open the script folder

Keep download_assets.py where release folders should be created, then open PowerShell in that directory.

Choose a launch mode

Run python3 .\download_assets.py for guided prompts, or use the generated command above for a direct, repeatable launch.

Collect the complete release

Press Enter and follow live progress for all attached assets and both source archives. The launcher reports a clear error and non-zero exit code if any transfer fails.

Useful details

Built for real release work.

What happens if I run the same command twice?

Existing assets with the same names are replaced only after their new downloads complete. Interrupted transfers remain temporary and are removed automatically.

What does interactive mode ask for?

The launcher requests the author or organization, the project or repository name, and the release tag. Empty values are rejected before any network request begins.

Can it download private repository assets?

The script supports a GITHUB_TOKEN environment variable. Set a token that has permission to read the repository before running the command.

What if GitHub applies an API rate limit?

Set $env:GITHUB_TOKEN = "your-token" in PowerShell, then run the command in the same session. Authenticated API requests receive a higher rate limit.

Where is the destination folder created?

Always beside the Python script—not in whichever folder the terminal happens to use. Characters that Windows does not allow in folder names are safely replaced.
